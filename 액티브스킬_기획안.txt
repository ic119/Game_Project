액티브 스킬 기획안 (2026-10-07)
================================================================

[확정 사항]
- 키: 숫자 1~4. 해금 레벨: 1=Lv3, 2=Lv6, 3=Lv9, 4=Lv12
- 구현 우선 무기: 한손검(OneHanded). 이후 완드 -> 양손검 -> 창
- 조준: 캐릭터 전방 고정 거리 (마우스 커서 지점 조준 사용 안 함)
- VFX: Assets/@ThirdParty/VFX_Klaus 와 Lana Studio 폴더에서 선택
- 스킬 레벨 성장 없음. 레벨 해금만 둔다.
- PvP 제외(몬스터만 피격). 상태이상(기절/넉백/슬로우)은 이번 범위 제외.

[공통 규칙]
- 슬롯 성격: 1=입문기(짧은 쿨, 낮은 코스트) / 2=범위·이동기 / 3=선딜 있는 강타기 / 4=궁극기
- 마나: 최대 마나 Lv3 약 66, Lv12 약 108. 4번 코스트는 최대 마나의 약 35%.
- 쿨다운 기준: 5s / 8s / 12s / 20s (무기별 편차 있음)
- 피해: 플레이어 공격력 x 배율, 방어력 차감은 기존 max(1, attack - defense)
- 캐스트 중: 이동/기본공격/다른 스킬 잠금, 대쉬로만 캔슬 가능
- 판정: 서버 권위. 형태는 직선/원/부채꼴. 선딜 스킬은 바닥 표시(텔레그래프)
- 서버에 무기 타입 권위 필요: ItemDefinitions.json 무기에 weaponType 추가

[애니메이션 메모]
- Attack04 클립은 전 무기 동일 길이: Start 0.20s / 본동작 0.53s / 후속 0.33s
- 현재 애니메이터는 SwordPierce(SkillIndex=1), Wheelwind(SkillIndex=4)만 한손검 전용.
  나머지는 SkillIndex로 분기하는 무기별 블렌드 트리 추가 필요(_WeaponBlend 방식).
- 타격 프레임은 미측정 -> 구현 시 슬롯별 hitDelay 튜닝.
