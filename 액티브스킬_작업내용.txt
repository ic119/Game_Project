     TryBeginSkillCast : 검사 순서 = 방/생존 -> 무기+슬롯 스킬 존재 -> 해금 레벨 -> 시전 잠금 -> 쿨다운 -> 마나

     BroadcastSkillCast: 주변 플레이어에게 모션용 중계(본인 제외)
 - GameRoom.Dash.cs : 대쉬 성공 시 CancelSkillCast 호출 (대쉬로 시전 캔슬)
 - ClientSession.Skills.cs : 요청 처리(속도 제한 4/3 per s), 결과 전송, RunSkillHitsAsync 로 타격 예약
     (시전자 사망/방 이동/시전 취소 시 남은 타격 중단)
 - ClientSession.Combat.cs : 킬 보상 후처리를 ProcessMonsterAttackResult 로 분리해 기본공격/스킬 공용
 - 패킷/OpCode : Game_SkillRequest 0x022E (C2S: PlayerId, Slot, RotationY)
                 Game_SkillResult 0x022F (S2C 본인: Slot, Status, CooldownSeconds)
                 Game_SkillCastBroadcast 0x0230 (S2C 주변: PlayerId, Slot, WeaponType, X,Y,Z, RotationY)
     SkillCastStatus: Accepted0 Dead1 NoSkill2 LevelTooLow3 OnCooldown4 NotEnoughMana5 Casting6 InvalidRequest7
     다음 빈 OpCode = 0x0231
